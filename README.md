# Портфолио QA Engineer

За спиной — десятилетия опыта в управлении качеством сложных технических процессов. Это научило меня:
- Выявлять корень любой проблемы;
- Объяснять сложные вещи простым языком;
- Реализовывать каждую задачу до конца.

***

## 🧪 Опыт краудтестирования

* **VK Testers** — бета-тестирование продуктов VK: 40 оформленных баг-репортов, 13 из них приняты и оплачены.
* **CrowdTesting** — участие в краудтест-проектах мобильных приложений (NDA, репорты проходят валидацию QA-экспертов).
* **Kwork** — тестирование Android-приложений на заказ: отчёт с шагами воспроизведения, скриншотами и приоритетами за 48 часов —  [kwork.ru — тестирование Android](https://kwork.ru/usability-testing/55058985/testirovanie-mobilnykh-prilozheniy-android-otchyot-za-48-chasov?ref=25399863);

## 📁 Артефакты проекта и результаты тестирования

* **Тестирование API**: В папке [postman_screenshots](./postman_screenshots) находятся скриншоты успешного прогона автотестов для GET и POST запросов с автоматической верификацией ответов сервера.
* **Баг-репорты**: В папке [bug_reports](./bug_reports) находится оформленный PDF-отчет о найденном дефекте в модуле API по всем стандартам разработки.
* **Работа с базами данных**: В файле [queries.sql](./queries.sql) собраны практические SQL-запросы (фильтрация WHERE, объединение таблиц INNER JOIN, агрегация GROUP BY), которые применялись для валидации данных на бэкенде.
