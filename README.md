# Портфолио Junior QA Engineer

За спиной — десятилетия опыта в управлении качеством сложных технических процессов. Это научило меня:
- Выявлять корень любой проблемы;
- Объяснять сложные вещи простым языком;
- Реализовывать каждую задачу до конца.

***

В репозитории вы найдёте примеры моей работы:
- Оформленные баг-репорты по шаблону Jira;
- Коллекцию запросов в Postman с автоматическими тестами;
- Элементарные SQL-запросы для проверки целостности данных.
