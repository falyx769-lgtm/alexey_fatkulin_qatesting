Документация Booking.
Мобильное тестирование сайта Booking.com
В этой папке собраны реальные UI/UX дефекты адаптивности, вёрстки и локализации интерфейса, найденные в ходе исследовательского тестирования мобильной версии сайта.

# Booking.com (mobile) баг-репорты

Структура файлов:

**Основной файл** (описание бага):
`bk-<номер>-description.md` — содержит подробное описание дефекта

**Дополнительный файл** (скриншот):
`bk-<номер>-screenshot.png` — визуальное подтверждение проблемы

Пример для кейса 03:
- `bk-03-description.md` — текстовый файл с описанием проблемы (например, перекрытие хедера или обрезка кнопки)
- `bk-03-screenshot.png` — скриншот проблемы

В файле description.md подробно описывается:
* Тип дефекта (header-overlap, button-cut и др.)
* Шаги воспроизведения
* Ожидаемый/фактический результат
* Окружение
