# Wildberries — мобильное тестирование главной страницы

**Объект:** мобильное приложение Wildberries (Android 16, Samsung Galaxy Z Flip7)

**Что проверял:** исследовательское тестирование главной страницы — карусель рекламных баннеров

**Найдено:** нарушение адаптивности карусели баннеров — контент баннеров обрезается по краям экрана, текст и графические элементы «нарезаются» при прокрутке
